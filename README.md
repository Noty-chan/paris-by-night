# Paris // Nuit

Неофициальный помощник для домашней хроники **Vampire: The Masquerade V5** в Париже нулевых.

Первая версия включает:

- локально сохраняемый лист персонажа V5;
- бросатор с костями Голода и автоматической интерпретацией;
- книжный справочник с поиском, краткими пересказами и печатными страницами источников;
- шаблоны для будущих персонажей, фракций, мест и слухов.
- каркас игроковой педии для районов, фракций и важных лиц.
- разделы основной книги V5 и In Memoriam: Дисциплины, преимущества, недостатки, стили охоты, Океаны Времени, ретроспективы, создание и правила стола.

## Источники правил

Авторитетны предоставленные ведущим основная книга V5 (`STV501_Kniga_pravil.pdf`) и `V5_-_In_Memoriam.pdf`. Прежний веб-источник исключён. Книги и полные текстовые выгрузки не публикуются; карточки — краткие самостоятельные пересказы. Непокрытые дополнения и неоднозначности перевода обозначены явно. Проверка обычного старта листа не является валидатором создания анцилл по In Memoriam.

Существующие JSON, localStorage и сырые поля прежнего PDF сохраняются. Импорт старого PDF — совместимость формата, не подтверждение правильности его правил.

«Создание» (`#create`) — пошаговый редактор того же локального листа: выборы из книжного каталога, подсказки распределения, подстановка названий клана и расчёт производных шкал. Пакеты охоты, эпох и анциллы не начисляются автоматически. Шаг хранится в адресе; персонаж — существующим механизмом сохранения App.

Справочник показывает по 12 карточек, поддерживает общий поиск, фильтр дисциплин и прямые ссылки на карточку независимо от её страницы. На телефоне разделы и шаги выбираются компактно. Лирические вставки и длинные примеры остаются в книгах.

## Игровой архив

Раздел «Архив» предназначен только для знаний, доступных персонажам. Мастерский канон хранится отдельно от репозитория и не должен импортироваться в исходный код или публичную сборку.

Данные прототипа находятся в [`src/data/pedia.ts`](src/data/pedia.ts), а представление — в [`src/components/EncyclopediaPage.tsx`](src/components/EncyclopediaPage.tsx). У записи явно указывается состояние знания:

- `public` — общедоступный факт;
- `rumor` — слух без гарантии истинности;
- `discovered` — сведения, открытые персонажами во время хроники.

Профиль территории адаптирует четыре оси Homesteading из *Chicago by Night*: капитал, поток, контроль и сервисы. Рейтинги описывают характер места, но сами по себе не дают постоянных модификаторов к броскам. Игровые последствия записываются отдельно как «правила ночи» и должны применяться только в подходящих сценах.
