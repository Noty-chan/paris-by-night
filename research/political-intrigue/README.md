# Политическая хроника: исследовательские конспекты

Эти заметки — не канон **Paris // Nuit**, а рабочие инструменты. Перед проектированием фракций, крупных NPC, раскрытий и очередного сюжетного узла стоит сверяться с соответствующим блоком.

## Блоки

2. [Политические настольные ролевые игры](02-ttrpg.md)
3. [Политика в Vampire: The Masquerade](03-vampire.md)
4. [Синтез: наша доктрина](04-synthesis.md)

## Принцип использования

- Источники дают вопросы и инструменты, а не готовый сюжет.
- Советы из прозы применяем к правдоподобию мотивов и власти.
- Советы из НРИ применяем к агентности игроков и подготовке ситуаций.
- Советы Vampire применяем к личному ужасу, долгам, крови и отношениям.
- Если красивый замысел противоречит свободному выбору игроков, меняем замысел.
