# Канон хроники

Это мастерское хранилище проекта. Папка лежит рядом с исходниками сайта намеренно и не импортируется в приложение.

- сайт собирается из `src/` и `public/`;
- файлы здесь не отображаются в «Архиве» автоматически;
- материалы могут содержать скрытую правду, рабочие гипотезы, NPC и сюжетные узлы;
- перед публикацией игрокам нужно отдельно отбирать безопасный слой.

Синхронизация с внешним локальным vault выполняется вручную. Если канон меняется, сначала обновляем эту папку, затем решаем, что (если вообще что-то) переносить в `src/data/pedia.ts`.
